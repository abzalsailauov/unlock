# UNLOCK 1.2 — личное приложение для iPhone 💚

**Сначала полезное дело → потом заслуженный отдых.**

Открыть приложение: https://abzalsailauov.github.io/unlock/

UNLOCK работает бесплатно как приложение с главного экрана iPhone. Устанавливать из App Store не нужно.

## Что нового в версии 1.2

- **Подробное описание задачи.** При создании или изменении задачи можно записать цель, пояснения, план действий и заметки (до 4000 символов). Описание раскрывается нажатием на карточке задачи.
- **Свои папки.** Кнопка «+ Папка» → название, какое хочешь. Например, «Утро», «Спорт», «Учёба». Можно создать сколько угодно папок, переименовывать и удалять их.
- **Задачи можно распределять по папкам.** В окне добавления или редактирования задачи есть поле «Папка». Если выбрана папка в списке, новые задачи автоматически попадают в неё. Можно переносить задачи между папками через «Изменить».
- **Удаление папки НЕ удаляет её задачи.** Они автоматически перемещаются в «Без папки»; история выполнений сохраняется.
- **Лимитов заработанных минут больше нет.** Убраны дневной максимум 120 минут и ограничение баланса. Можно заработать и накопить столько минут, сколько захочешь.
- **Минуты переносятся на следующий день.** В полночь обновляется только показатель «Заработано сегодня», а весь оставшийся баланс сохраняется.
- **Своя длительность отдыха.** Помимо быстрых вариантов можно ввести количество минут вручную.
- Сохранены работающие таймеры, статистика, история и связь с Apple «Командами».

### Как пользоваться папками

1. Открой UNLOCK и нажми «+ Папка» рядом с «Мои папки».
2. Введи своё название, например **Утро**.
3. Нажми «+ Задача», напиши название и добавь подробное описание.
4. Выбери, сколько минут займёт дело и сколько минут отдыха за него получишь.
5. Нажми «Сохранить». Задача окажется в выбранной папке.
6. Чтобы сменить папку, нажми «✎» у задачи.
7. Чтобы переименовать или удалить папку, сначала открой её вкладку и выбери соответствующую кнопку.

Все старые задачи без папки останутся в разделе **«Без папки»** после обновления.

## Связь с соцсетями через «Команды»

Бесплатная инструкция: https://abzalsailauov.github.io/unlock/shortcuts.html

Создаются две команды:
- `UNLOCK START` — включает режим «Фокусирование» `UNLOCK FREE` на заданное время;
- `UNLOCK STOP` — выключает его при паузе или досрочном завершении отдыха.

Автоматизация iPhone реагирует на открытие Instagram, TikTok или YouTube: если режим `UNLOCK FREE` не включён, она может вернуть на главный экран. Это **мягкое ограничение**, а не настоящая блокировка приложений.

## Где хранятся данные

В **localStorage** на самом iPhone, где установлен UNLOCK. GitHub хранит код приложения, а не ваши личные задачи и историю.

- При обычном закрытии, обновлении сайта и перезагрузке iPhone данные должны сохраниться.
- При удалении установленного приложения, очистке хранилища Safari или смене телефона данные могут пропасть.
- Для защиты используй **История → Сохранить копию**, затем перенеси файл в «Файлы» → iCloud Drive.
- Для восстановления: **История → Вернуть копию**. Копия включает задачи, их описания, папки, историю, статистику и баланс; восстановление заменяет текущие данные.

Важно: установленная версия с главного экрана и сайт в Safari на iPhone могут иметь разные хранилища. Лучше пользоваться привычной иконкой UNLOCK.

## Технические файлы

- `index.html` — интерфейс, задачи, папки, таймеры, награды, статистика и сохранение.
- `shortcuts.html` — инструкция по бесплатной настройке iPhone.
- `sw.js` — кеширование для работы без сети после первого открытия.
- `manifest.webmanifest` — описание веб-приложения для установки.
- `icon.svg` — иконка.

Приложение не использует платные API, серверы и базы данных.
