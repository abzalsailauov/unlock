# UNLOCK — бесплатное PWA-приложение для iPhone

**Сначала полезное дело → потом социальные сети как награда.**

Готовый MVP без сервера, аккаунта, рекламы, сборки и платных API. HTML + CSS + JavaScript; данные остаются в локальном хранилище браузера на устройстве.

## Что уже работает

- Добавление, редактирование и удаление задач (название, минуты фокуса, минуты награды).
- Таймер фокуса: запуск, пауза, продолжение, досрочная остановка **без награды**.
- Автоматическое однократное начисление награды при завершении фокус-таймера, в том числе после повторного открытия приложения.
- Ручное подтверждение выполнения с начислением награды **один раз**.
- Кошелёк отдыха, выбор длительности, таймер отдыха с паузой и возвратом неиспользованного времени при досрочной остановке.
- Максимум **60 минут наград в сутки** и максимум **60 минут на балансе**. Неиспользованный баланс сгорает при смене календарного дня на устройстве.
- Дневной прогресс, статистика, список выполненных задач, серия активных дней.
- Экспорт и импорт резервных копий JSON.
- Сохранение задач, таймеров и статистики через `localStorage`.
- Оффлайн-кэш через service worker и установка на главный экран iPhone.

**Честные ограничения:** PWA не блокирует Instagram, TikTok или другие приложения и не показывает надёжные системные уведомления, если его выгрузила iOS. Таймер в фоне не обязан отрисовываться каждую секунду: после возвращения он автоматически пересчитывается по реальному времени. Ручное выполнение основано на доверии, а не на проверке фактической работы. Приложение не синхронизирует данные между устройствами. При очистке данных Safari прогресс может быть удалён — сохраняйте резервную копию.

## Самый простой способ опубликовать на GitHub Pages

1. Создайте бесплатную учётную запись на https://github.com (если её ещё нет).
2. Нажмите **New repository** → назовите репозиторий `unlock` → выберите **Public** → **Create repository**. Для бесплатного GitHub Pages репозиторий должен быть публичным.
3. Распакуйте `UNLOCK-MVP.zip`. В репозитории выберите **Add file → Upload files**, затем **загрузите содержимое папки `unlock-mvp`**, включая папку `icons`, а не саму папку верхним уровнем. `index.html` должен лежать в корне репозитория.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку `main`, папку `/(root)` → **Save**.
6. После публикации адрес будет примерно таким: `https://ВАШ-ЛОГИН.github.io/unlock/`. Точный адрес доступен в **Settings → Pages → Visit site**.

> Готовое приложение использует относительные пути `./`, поэтому корректно работает и на поддомене, и внутри папки `/unlock/` на GitHub Pages.

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес **в Safari**.
2. Нажмите **Поделиться** (в некоторых версиях iOS сначала кнопка меню страницы), затем **На экран «Домой»** / **Add to Home Screen**.
3. Если есть переключатель **Open as Web App / Открывать как веб-приложение**, включите его.
4. Нажмите **Добавить**, затем открывайте UNLOCK с новой иконки на экране iPhone.
5. Один раз откройте PWA при работающем интернете, дождитесь загрузки и затем проверьте запуск без сети (лучше в авиарежиме). Service worker устанавливает оффлайн-кэш при первой загрузке; сразу закрывать страницу не стоит.

## Как пользоваться

Начальный экран содержит три примерные задачи из вашего сценария; их можно изменить или удалить. Нажмите **Начать фокус** под задачей либо **Готово** для честного ручного подтверждения. Когда получены минуты, нажмите **Начать отдых** и выберите 5, 10, 15 или все доступные минуты. История и резервная копия находятся на второй вкладке.

## Файлы

| Файл | Роль |
|---|---|
| `index.html` | Экраны, диалоговые окна и доступная разметка |
| `styles.css` | Тёмный адаптивный дизайн для iPhone |
| `core.js` | Проверяемая логика задач, лимитов, статистики и таймеров |
| `app.js` | Работа интерфейса и `localStorage` |
| `manifest.webmanifest` | Установка PWA, standalone, иконки |
| `sw.js` | Автономная работа после загрузки |
| `icons/` | Иконки iPhone и PWA |
| `tests/` | Автоматизированные тесты логики |
| `.nojekyll` | Статические файлы без обработки Jekyll |

## Запуск локально (не обязателен для публикации)

Открытие `index.html` как `file://` **не подходит**: из-за ES-модулей и service worker нужен локальный веб-сервер или GitHub Pages.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Тесты логики (нужен Node.js версии 20+):

```bash
node --test tests/*.test.mjs
```

**Никакой npm install, регистрации или сборки не требуется.**

## Технические детали начислений

- Фокус фиксирует точное время окончания (`endsAtMs`), а не вычитает секунду внутри `setInterval`: это исправляет сбои фоновых таймеров iOS.
- Досрочно остановленный фокус не засчитывается. Ручное подтверждение доступно отдельной кнопкой в карточке задачи.
- Каждая задача после выполнения уходит из списка и попадает в историю с тем же идентификатором; повторное начисление невозможно обычным способом.
- При одновременном превышении лимита и награды начисляется только доступный остаток. Задача при этом всё равно считается выполненной.
- Пауза замораживает оставшееся время и сохраняется даже после закрытия приложения.
- Если таймер фокуса истёк до полуночи, но приложение открыли после полуночи, событие записывается датой завершения; старая награда не переносится в новый день.
- Если прервать отдых в тот же день, неиспользованная часть возвращается на баланс. В полночь любой активный или поставленный на паузу отдых завершится, а остаток сгорит. Это предотвращает перенос зарезервированных минут на завтра.
- История сохраняется между днями; счётчики ежедневной награды и баланс обнуляются при смене локальной календарной даты.
- `localStorage` не защищён от целенаправленной правки данных или перевода системных часов: для личного MVP это **игровой принцип доверия**.

## Обновления

Чтобы опубликовать новую версию, замените изменённые файлы в репозитории. При изменении содержимого `app.js`, `core.js` или `styles.css` также обновите версию `CACHE` в `sw.js`, чтобы уже установленные PWA получили свежий набор файлов. После публикации полностью закройте и снова откройте PWA (при необходимости ещё раз с интернетом).
