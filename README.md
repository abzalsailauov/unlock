# UNLOCK 1.1 — продуктивность вместо бесконечного скроллинга

Сайт и PWA для iPhone: https://abzalsailauov.github.io/unlock/

UNLOCK бесплатно хранит задачи и статистику на вашем iPhone. Нет серверов, платных API, аккаунтов или платных подписок.

## Новое в 1.1 (15 ноября 2026)

- Лимит заработанных и доступных минут отдыха увеличен с **60 до 120 минут в день**.
- Для одной задачи можно назначить до 120 минут награды.
- Добавлена кнопка **«Разрешить соцсети на iPhone»** внутри активного отдыха. Она открывает Apple «Команды» через URL и передает **точное количество оставшихся секунд** в команду `UNLOCK START`.
- При паузе или досрочном завершении отдыха приложение пытается запустить `UNLOCK STOP` и выключить специальный режим «Фокусирование» (если доступ был запущен из приложения).
- Добавлена страница с подробной бесплатной настройкой: https://abzalsailauov.github.io/unlock/shortcuts.html
- Обновлён автономный кэш для нового интерфейса и инструкции.

## Связь с «Командами» Apple

На iPhone нужно **один раз** вручную настроить:
1. Собственный режим «Фокусирование» с точным названием `UNLOCK FREE`.
2. Команду `UNLOCK START`:
   - получить текущую дату;
   - изменить дату: прибавить **Shortcut Input** секунд;
   - включить `UNLOCK FREE` до полученной даты.
3. Команду `UNLOCK STOP`, которая выключает `UNLOCK FREE`.
4. Автоматизацию **когда Instagram/TikTok/YouTube открываются**: получить текущее фокусирование → если имя не равно `UNLOCK FREE`, выполнить «Перейти на экран Домой». В режиме `UNLOCK FREE` приложения продолжают открываться.

Подробнее: [Настроить «Команды»](https://abzalsailauov.github.io/unlock/shortcuts.html).

### Реальные ограничения

- Это **не настоящая системная блокировка** приложений: автоматизация может быть отключена, а проверка срабатывает только при открытии/переключении на приложение.
- Время отдыха идёт по часам даже если пользователь не открывает соцсети. Время фактического использования других приложений не измеряется.
- PWA не может прочитать или проверить, запустились ли `UNLOCK START` / `UNLOCK STOP`. Если автоматизация или Shortcut не настроены, сам по себе сайт соцсети не ограничит.
- Автоматическое закрытие *уже открытой* соцсети при окончании минут в этой версии не гарантируется.
- Таймеры пересчитываются после возвращения в PWA; фоновые уведомления не гарантируются.
- Состояние хранится в localStorage браузерного веб-приложения. Safari и приложение с иконки могут иметь разные хранилища. Для сохранения данных используйте «История → Сохранить копию».

## Как открыть на iPhone

1. Откройте https://abzalsailauov.github.io/unlock/ в Safari.
2. Нажмите «Поделиться → На экран Домой → Добавить».
3. Пользуйтесь приложением с появившейся иконки UNLOCK.
4. Для связи с соцсетями откройте раздел «Настроить Команды» прямо в приложении.

## Технические файлы

- `index.html` — интерфейс, таймеры, задачи, статистика, вызов Shortcuts URL.
- `shortcuts.html` — инструкция для iPhone, доступная офлайн.
- `sw.js` — автономный кэш PWA.
- `manifest.webmanifest` — описание приложения для установки.
- `icon.svg` — иконка.
- `README.md` — этот файл.

## Короткая проверка

1. Создайте задачу, выполните, убедитесь что начислены минуты, максимум 120 в день.
2. Запустите отдых, нажмите «Разрешить соцсети на iPhone». Должна выполниться `UNLOCK START`.
3. Переключитесь на Instagram, проверьте что режим `UNLOCK FREE` разрешает остаться.
4. Завершите отдых досрочно: UNLOCK возвращает неиспользованные минуты и пытается вызвать `UNLOCK STOP`.
5. Откройте Instagram повторно: автоматизация должна вернуть на экран Домой, если фокусирования нет.
6. Для офлайн-теста сначала один раз откройте обновлённый UNLOCK при интернете, затем отключите сеть, закройте и вновь откройте приложение.
