# UNLOCK — личное приложение для iPhone

Приложение создано и бесплатно размещается через GitHub Pages.

## Как открыть на iPhone

1. Откройте **Settings → Pages** этого репозитория: https://github.com/abzalsailauov/unlock/settings/pages
2. В разделе **Build and deployment** выберите **Deploy from a branch** (если выбрано GitHub Actions, тоже можно, но сначала требуется разрешить Actions).
3. Выберите ветку **main** и папку **/(root)**, нажмите **Save**.
4. Откройте https://abzalsailauov.github.io/unlock/ в Safari.
5. Нажмите **Поделиться → На экран «Домой» → Добавить**.

## Что работает

- Создание, изменение, удаление задач и отметка о выполнении.
- Фокус-таймер с паузой, продолжением и восстановлением после закрытия.
- Награда только один раз за задачу, лимит 60 минут в день и на балансе.
- Таймер отдыха, пауза, досрочное завершение с возвратом неиспользованного времени.
- История, статистика за день, серия продуктивных дней.
- Данные сохраняются локально в браузере. Есть экспорт и импорт резервной копии.
- Офлайн-режим после первой успешной загрузки.

## Техническая часть

Это упрощённая, самодостаточная версия: весь интерфейс и логика в `index.html`, установка в `manifest.webmanifest`, кеширование в `sw.js`, значок в `icon.svg`. Нет сервера, платных API и сторонних библиотек.

Важные ограничения: приложение не блокирует социальные сети и не может гарантировать системные уведомления в фоне. Таймеры пересчитывают оставшееся время по системным часам после возвращения. Данные хранятся на том устройстве, где вы используете приложение; при очистке хранилища они могут исчезнуть, поэтому сохраняйте резервные копии.
