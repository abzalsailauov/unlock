Подружим UNLOCK
с соцсетями.

Понадобится бесплатное приложение Apple «Команды», которое уже есть на большинстве iPhone. MacBook сейчас не нужен.

Что получится: без активного отдыха Instagram, TikTok и YouTube будут автоматически отправлять тебя на главный экран iPhone. Во время заработанного отдыха эти приложения можно открывать. Это мягкое ограничение, а не настоящая блокировка Apple Screen Time.
ШАГ 1

Создай режим отдыха

  1. Открой Настройки iPhone → Фокусирование.
  2. Нажми + → Другое (или «Собственный»).
  3. Назови режим точно UNLOCK FREE и сохрани.
  4. Не добавляй расписание включения. Настройки уведомлений можно оставить удобными для себя.

Этот режим сам ничего не запрещает. Он нужен как «зелёный свет» для следующей настройки.

ШАГ 2

Создай команду «Начать отдых»

  1. Открой приложение Команды → + → новая команда.
  2. Назови её точно UNLOCK START.
  3. Добавь действие Текущая дата (Current Date).
  4. Добавь действие Изменить дату (Adjust Date). Настрой: прибавить к текущей дате число из переменной Входные данные команды (Shortcut Input), единицы — секунды.
  5. Добавь действие Установить фокусирование (Set Focus): UNLOCK FREE → Вкл. → До времени → выбери результат «Изменить дату».
  6. Сохрани команду.

Когда нажмёшь кнопку отдыха в UNLOCK, приложение передаст в эту команду нужное количество секунд. Режим выключится автоматически по истечении времени.

ШАГ 3

Создай команду «Закончить отдых»

  1. В приложении Команды создай ещё одну команду.
  2. Назови её точно UNLOCK STOP.
  3. Добавь одно действие Установить фокусирование (Set Focus): UNLOCK FREE → Выкл.
  4. Сохрани.

UNLOCK будет вызывать её при паузе или досрочном завершении отдыха, если ты запускал доступ через кнопку в приложении.

ШАГ 4

Научи iPhone замечать соцсети

  1. В приложении Команды открой вкладку Автоматизация → нажми +.
  2. Выбери Приложение (App), затем Instagram, TikTok, YouTube и другие нужные приложения.
  3. Отметь Открыто (Is Opened), выбери Запускать немедленно (Run Immediately).
  4. Выбери Новая пустая автоматизация (New Blank Automation).
  5. Добавь Получить текущее фокусирование (Get Current Focus).
  6. Добавь Если (If): у текущего фокусирования свойство Имя (Name) не равно UNLOCK FREE.
  7. Внутри «Если» добавь Перейти на экран «Домой» (Go to Home Screen). После него можешь добавить уведомление «Сначала выполни задачу в UNLOCK».
  8. Закрой условие Конец если (End If) и нажми Готово.

Важно: если UNLOCK FREE включён, ничего не делай — просто оставь соцсеть открытой. Если режима нет, iPhone возвращает тебя на экран Домой.

ШАГ 5

Проверка

  1. Когда режим UNLOCK FREE выключен, попробуй открыть Instagram. Он должен вернуть тебя на главный экран.
  2. Открой UNLOCK с его обычной иконки на iPhone. Выполни задачу, получи минуты отдыха.
  3. Нажми «Начать отдых», выбери минуты, затем «Разрешить соцсети на iPhone».
  4. Если команда настроена правильно, включится UNLOCK FREE. Пока он работает, Instagram, TikTok и YouTube доступны.
  5. После окончания времени попробуй открыть приложение ещё раз: автоматизация должна снова вернуть тебя домой.

Если что-то не срабатывает

Проверь точные названия UNLOCK START, UNLOCK STOP и UNLOCK FREE. Убедись, что автоматизация включена и разрешён немедленный запуск. Если при нажатии в UNLOCK открылось приложение «Команды», но режим не включился, попробуй запустить UNLOCK START вручную и посмотри, какая ошибка появится. Можешь прислать мне скриншот — разберём шаг за шагом.

Важно знать о границах этой системы

Это добровольное ограничение, которое можно обойти или выключить. Время отдыха отсчитывается по часам даже тогда, когда соцсети закрыты, а не по фактическому времени их использования. Автоматизация «Открыто» срабатывает при запуске или переключении на приложение, но не обязана закрыть уже открытый Instagram ровно в момент окончания времени. На разных версиях iOS название некоторых пунктов может чуть отличаться. UNLOCK — веб-приложение и не умеет прочитать, включилось ли фокусирование на самом деле.

Совет: открывай UNLOCK через иконку на главном экране, а не через Safari. Данные веб-приложения и Safari на iPhone могут храниться отдельно.
